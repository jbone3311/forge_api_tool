# Image Settings Thumbnails

This directory contains thumbnail images that represent different image generation settings.

## How it works:

1. Each image file should be named to match a corresponding settings file
2. For example: `concept_art.jpg` corresponds to `concept_art.json`
3. The interface will show these thumbnails for visual settings selection
4. Supported formats: JPG, PNG, WEBP

## File naming convention:
- Settings file: `concept_art.json`
- Thumbnail: `concept_art.jpg` (or .png, .webp)

## Thumbnail requirements:
- Recommended size: 300x300 pixels
- Should represent the style/type of images generated with those settings
- Keep file sizes reasonable (under 100KB recommended)

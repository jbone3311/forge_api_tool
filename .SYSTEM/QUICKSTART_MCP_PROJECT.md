# QUICKSTART_MCP_PROJECT.md

## First Step: Initialize Your Project

1. **Open Cursor.ai in your project directory.**
2. **Prompt the LLM:**
   > "I’m starting a new project called ‘PROJECT’. Please read `.SYSTEM/INIT_NEW_PROJECT.md` and follow its instructions to initialize the project."

3. **Follow the LLM’s guidance as it works through the steps in `.SYSTEM/INIT_NEW_PROJECT.md`.**

---

## Example Prompts for the LLM

- "Scan the codebase and create an initial knowledge graph of modules, dependencies, and key concepts. Store the graph in `.PROJECT-SPECIFIC/knowledge-graph/`."
- "Create a project memory file in `.PROJECT-SPECIFIC/` that summarizes the project’s goals, architecture, and any important decisions."
- "Show me the index of all user guides in this project."
- "Summarize the key steps from `.SYSTEM/USER_GUIDE_SETUP.md` for setting up the environment."

---

**All other guides are indexed in `.SYSTEM/USER_DOCS_INDEX.md`.**
